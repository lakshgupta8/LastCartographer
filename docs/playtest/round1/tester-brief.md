# The Last Cartographer: playtest

Thank you for playing. This is an early version of the game, so the art is unfinished, the sound is placeholder
and some things will break.

**We are testing the game, not you.** If you get lost, stuck or frustrated, that is exactly what we need to see.

## What to do

- Play from the start, the way you would play any game at home.
- Stop whenever you like. About an hour is plenty.
- The test ends when you beat the lighthouse's keeper (the Lamp-Keeper). The game will tell you; you can stop
  there or keep going.
- Please don't ask us how to do things while you play. If you'd normally give up or look it up, say so out loud
  and carry on as best you can.
- Thinking aloud helps a lot ("I think I'm meant to go up there…"), but only if it feels natural.
- When you stop, we'll ask you twelve quick questions (one to five) and a few open ones.

## Controls

| | Keyboard | Controller |
|---|---|---|
| Move | WASD or arrow keys | left stick or d-pad |
| Jump (hold for higher) | Space | A / ✕ |
| Quill (attack) | J | X / □ |
| Bind (heal) | E | B / ○ |
| Survey (at a vantage) | Q | Y / △ |
| Dash (once you have it) | Shift or K | right bumper |
| Talk, read | Up | Up |
| Next line in a conversation | Space or J | A / ✕ |
| Atlas (map) | M | View / Select |
| Menu | Esc | Start / Options |
| **Report a bug** | **F12** | (ask us) |

In the menu (Esc) you can change the controls, the volume, the contrast, how long captions stay up, and turn down
the screen shake.

## If something breaks

- **Press F12.** It saves a short report with a picture of the screen and your save, so we can see what happened.
  Then carry on.
- **If the game freezes or closes,** tell us. We'll restart it, and your progress carries on from the last time
  you rested.

## What we record

While you play, the game notes:
- which rooms you go through and how long you spend in each;
- where you fall;
- the boss attempts;
- what you read;
- any errors.

It records nothing else: no keystrokes, no video, no microphone.

The notes stay on this computer under the name you give us, which can be a nickname. Your answers are kept with
them. We use them only to improve the game, and we'll delete them if you ask.
